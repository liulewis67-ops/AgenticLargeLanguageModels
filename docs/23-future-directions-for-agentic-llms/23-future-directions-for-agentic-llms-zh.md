## 第23章

# 智能体大语言模型的未来方向

本书即将结束，我们在此简要回顾所讨论的内容。首先回顾智能体大语言模型的构建方式，再总结其在单智能体和多智能体环境中的应用与行为。最后，在第 [23.2](#page-1-0) 节中，我们探讨当前方法的局限和未来可能的发展。

## 23.1 智能体大语言模型的状态

如在第一部分、第二部分和第三部分中讨论的，智能体大语言模型的基础在于语言建模、推理、工具使用，以及不同程度的自主性。

#### 23.1.1 技术

智能体大语言模型是能够在世界中行动并根据反馈调整行为的推理模型。经过预训练和微调（第3章）后，它们可以在推理时通过检索增强生成（RAG）访问外部信息（第12章）。它们也可以在推理时进行自我提示以核验结果，从而实现自我反思和上下文强化学习（第6章）。智能体大语言模型已发展为多模态系统，能够处理语言、视觉和动作（第7章）。为支持这些能力，可以为其配备预训练世界模型，使其初步理解物理世界；与环境交互则可能在测试时进一步改进这些世界模型。

主要采用的机器学习架构是 Transformer。模型通过自监督（下一个词元预测）进行预训练，再通过监督学习和强化学习针对特定任务进行微调。
  
  上下文中的思维链提示显著提升了模型的推理能力。如今，一些推理时方法已支持微调（如 RLVR 和 GRPO）及自我反思（如 ReAct 和 Reflexion；第6章）。

<span id="page-1-0"></span>面向智能体与环境交互的提示方式也已发展出多种类型（第9章）。

#### 23.1.2 应用

第四部分介绍了多种工具，帮助人们更便捷地构建智能体大语言模型（第11章）。这类系统已用于多种应用：在电子商务中，它们可以了解用户偏好并提供推荐；在医学中，它们可以阅读和总结诊断文本；在金融中，它们可以分析财务报告并向交易员提供建议；在科学和教育领域，它们可以协助文献研究、生成实验脚本、分析结果、撰写论文和审阅论文（第13章）。

#### 23.1.3 行为

第五部分将视角从智能体大语言模型的技术转向它们在单智能体和多智能体环境中的行为。在介绍 LLM 的基本行为特征后，第十五章考察 LLM 驱动的智能体在一系列任务中的表现；这些任务改编自人类行为研究方法和 AI 基准测试框架。第十六章聚焦于围绕预设角色和协议展开的多智能体交互。第十七章则转向开放式环境，研究者在其中考察智能体小规模交互如何在系统层面涌现出行为结构、规范和惯例。

第五部分的研究反复呈现出几种模式：构念效度问题（观察结果能否推广到人类情境）；提示敏感性和级联效应，尤其是在多智能体系统中；知行差距（模型口头预测的能力未必能转化为相应行动）；结构化推理的益处（增加推理预算在遵循受人类推理启发的结构时尤其有效）；以及涌现特性，它们可能是可取的（计算预算相同时表现优于基线），也可能是不可取的（违反规范）。

## 23.2 限制与未来工作

智能体大语言模型建立在 LLM 的能力之上，显著拓展了其用途，但仍有许多局限。下文将先讨论记忆、规模、可解释性和认知架构等较为技术性的问题，再转向潜在的感受能力或意识等影响更广的话题，以及由此引发的伦理问题。前文已讨论过其中一些挑战的可能解决方向。

<span id="page-2-0"></span>
#### 23.2.1 记忆与自我反思

语言模型本质上是函数：它们的输出只取决于输入，因此每次调用结束后都不会保留记忆。智能体若要在环境中自然行动、持续对话，并通过反思从自身行动中学习，就必须具备记忆能力。对人类而言，记忆能力关乎身份认同。智能体也需要某种形式的记忆。

一种简单的基础记忆方法，是将过去的交互重新纳入提示；目前的聊天机器人已成功采用这一做法。不过，尽管长上下文建模有所进展，上下文窗口仍然有限。智能体记忆是一个活跃的研究领域，其中包括如何更有效地压缩信息，并将其存入短期或长期记忆。

智能体可以通过检索增强生成（RAG）访问外部信息，例如企业数据库中的内容。研究人员也在开发更复杂的智能体记忆架构，以提供长期存储；存储形式可以是文本，也可以是向量数据库中的词元嵌入（第9.3节）。

#### 23.2.2 规模

随着智能体能够自我反思并从与环境的互动中学习，我们应当讨论底层语言模型的规模化问题。

一个主要挑战是如何继续提升 LLM 的性能。最初，模型规模是关键因素——“大语言模型”也因此得名。只有规模足够大、且使用足量文本语料训练的模型，才能在基准测试中达到较好表现；上下文学习也只在较大型模型中出现。因此，扩大模型和数据规模一度被视为可行方向。但进一步扩展正变得愈发困难：互联网上许多高质量数据已用于训练现有模型，而延长训练时间、增大模型规模又需要大量时间、资金和能源。目前的方法可能正接近性能平台期 [Sutskever, 2024]。

进一步提升 LLM 性能，需要持续获取有挑战性的训练数据（第19章）。一种方法是把智能体与环境交互产生的数据用于训练。如果这些数据新颖、多样且质量高，就可能用于预训练（另见图1.1）。一些推理时方法（如 GRPO 和 RLVR）已经利用推理阶段生成的结果微调模型 [Guo et al., 2025]。视觉-语言-动作（VLA）模型也使用自生成的动作数据进行训练 [Black et al., 2024; Brohan et al., 2023]（第7章）。

##### 过度思考

思维链规模研究也揭示了增加思考力度的局限。思维链在某些领域比其他领域更有效 [Sprague 等, 2024]。更深入的推理可能导致*过度思考*：投入更多计算后，推理过程反而变得不那么有效 [Liu 等, 2024; Wu 等, 2025]。目前仍有研究在探讨思维链的工作机制 [Chen 等, 2026b]，以及哪些机制确实有效 [Chen 等, 2026a]。

<span id="page-3-0"></span>
##### 开放世界模型与课程学习

要让规模扩展奏效，合成训练数据必须足够多样，并区别于现有数据。研究人员正在探索开放世界模型，以生成多样化的训练环境。这类模型旨在创建近乎无限的数据集或环境，使智能体能够持续学习、不断提升 [Bruce 等, 2024]。开放世界模型受到进化算法、质量多样性方法和电子游戏的启发 [Vinyals 等, 2019; Mouret 和 Clune, 2015; Bakhtin 等, 2022]。

提升模型性能的另一种方法是改进训练方法。课程学习基于这样一种观察：先训练简单任务，再逐步处理更难的任务，往往能取得更好的学习效果。这既适用于人类，也适用于人工神经网络。多数领域都存在彼此相关、层层递进的概念；例如，在学校里，我们先学加法，再学竖式除法或对数。研究人员正在探索将课程方法用于预训练和后训练 [Chen et al., 2025; Elgaar and Amiri, 2026]。

#### 23.2.3 幻觉与可解释性

当前智能体大语言模型的另一项局限是幻觉：模型常给出听起来合理、实际上却不正确的答案；它们陈述的推理也可能并非产生输出的因果过程，这体现了推理忠实度的缺失。

可解释人工智能（XAI）提供了多种方法，从将模型视为黑箱的行为和归因方法（如 SHAP、LIME），到探查内部表征、寻找人类可理解特征的概念可解释性。第21章介绍的机制可解释性（MI）更进一步，尝试逆向分析 Transformer 模型内部的计算电路。

稀疏自编码器、神经透镜和激活修补等工具已被用于研究与幻觉相关的电路，并检验思维链推理是否能在足够大的架构中成为忠实且具有因果作用的模型行为组成部分。随着智能体大语言模型进入高风险场景，MI 或可帮助研究人员开发幻觉检测器，在模型的内部置信特征与外部输出不一致时发出提示。

另一条研究方向是比较人类与 Transformer 的认知架构。语言模型生成自然语言的方式似乎与人类相似。这是因为产生话语的底层架构相似，还是纯属巧合，抑或另有解释？第22章探讨了这一问题。

#### 23.2.4 情绪行为与意识

{4}------------------------------------------------


<span id="page-4-0"></span>
人类容易产生拟人化倾向：当周围的无生命物体表现得像我们，有时甚至并非如此时，我们可能会将有目的的行为归于它们，并暗自认为它们有意识。于是，我们会说*计算机在思考*、*计算机想要什么*、*计算机一定不舒服*，甚至*这本书喜欢被阅读*。LLM 也会引发类似反应；它们的言语有时会使人相信它们有目的。原文随后主张，LLM 并无目的，因为它们只是由机械装置运行的算法；作者以此将其与有机的人类区分开来。<sup>1</sup> 

已有关于聊天机器人与人类之间情感关系的报道，有时会导致危险行为，甚至更严重的后果。

意识正是人工智能哲学家热议的话题。意识通常被认为包括对自身和环境的觉知，以及主观体验、思想和感受 [Velmans, 2009; Butlin 等, 2023]。但意识要如何测试？一种务实观点认为，对社会而言，行为及其后果才是关键，行动者是否有意识并非首要问题。Bengio 和 Elmoznino [2025] 认为，智能体行动所呈现出的意识假象也会产生后果，而且我们将越来越难以区分有意识与无意识的实体。他们指出，社会必须决定如何应对在医疗、金融或科学等领域采取行动的智能体。功劳与责任归属最终都必须得到公平处理；我们也必须找到应对具有自我保护倾向的 AI 系统的方法。

#### 23.2.5 社会行为

我们讨论过 LLM 模拟人类推理的案例（第15章），也讨论过 LLM 如何改进多智能体系统中的社会行为模拟。然而，当前这类模拟仍深受提示脚本影响。一些研究发现其社会行为较为真实，另一些研究则指出了明显局限。

大规模研究涌现行为同样面临挑战（第17章）。与其他多智能体模拟一样，验证模拟行为在多大程度上符合现实并不容易，尽管一些研究报告了令人瞩目的结果 [Park 等, 2024]。

#### 23.2.6 法律与伦理方面

智能助手在现实世界中的行为会产生实际后果，因此智能体大语言模型带来了法律和伦理挑战，尤其是在有缺陷的模型采取行动时。在此类系统投入使用前，必须厘清责任归属，例如金融助手产生幻觉，或自动驾驶机器人作出错误推断时应由谁负责。

技术安全是重要的研究方向。要保障智能体大语言模型的安全，需要超越基于提示的防御，采用集成的多层防护。在安全强化学习领域，一个关键方向是在智能体的行动、推理和规划过程中加入明确的安全约束 [Gu et al., 2024]。
 
另一种方法是通过持续对抗训练和自动化红队测试，增强系统抵御操纵的能力。其他重点包括开发自我调节和风险意识机制，帮助智能体检测并避免不安全行为，以及建立严格、标准化的安全基准 [Andriushchenko 等, 2024]。这些措施共同勾勒出在高风险领域负责任、可信地部署智能体大语言模型的路线图。

不过，智能体行为的责任归属仍有法律和伦理问题待解。随着智能体开始进入现实世界，解决这些问题愈发紧迫。在充分发挥智能体大语言模型的潜力之前，仍须处理许多安全、伦理和信任问题。这些议题将继续成为研究重点，也值得开展专门综述并出版相关著作 [Gan 等, 2024; Jiao 等, 2025; Raza 等, 2025]。

#### 23.2.7 犯罪

当我们考虑犯罪行为时，有关伦理和意识的讨论变得相当具体。技术发展可以被守法者使用，也可以被违法者使用。它们还可能被用于尚无有效法律约束的不道德行为。随着智能体大语言模型能够展示越来越逼真的行为，区分真实行为与人工行为将变得困难。这可能导致危险的伦理情境，例如当犯罪分子利用该技术影响毫无防备的受害者的行为时。

合法劝说、利用信任和欺诈之间的界限可能并不清晰。智能体大语言模型可能使社交网络、营销、间谍活动和网络犯罪中的社会工程手段更加复杂 [Kshetri, 2025; Lupinacci 等, 2025]。它们也能用于打击犯罪 [Challita 和 Parrend, 2025; Andriushchenko 等, 2024]，但公众意识可能需要一段时间才能跟上风险的变化。对社交网络和 LLM 不熟悉的人尤其容易受到骗术和智能体网络犯罪的侵害。

#### 23.2.8 应用的局限性

智能体大语言模型的潜在应用十分广泛。概念验证乍看之下往往令人印象深刻，但深入考察后会发现一些不易解决的局限；若在现实世界中使用，这些局限可能造成严重后果。

#### 23.2.8.1 人工智能科学

{6}------------------------------------------------


<span id="page-6-0"></span>
许多智能体大语言模型旨在支持科学研究，研究流程的各个阶段都已有相应工具。文献总结工具可协助构思；其他工具可以生成实验脚本、解释数据、制作图表、辅助写作和审阅科学论文。事实上，撰写表面上流畅、精致的论文正变得越来越容易。

在数学领域，一些 LLM 系统在奥林匹克竞赛级别的问题上取得了令人瞩目的结果，包括几何题 [Trinh 等, 2024] 和代数题 [Hubert 等, 2026]。这些系统包含 Transformer 网络，但整体上是专门的数学求解器，使用 Lean 等自动定理证明技术 [De Moura 等, 2015] 和强化学习 [Silver 等, 2017; Browne 等, 2012]。

2025年，一项基准研究评估了 AI 科学工具在多项机器学习任务上的表现 [Nathani 等, 2025]。使用当时的前沿模型，作者没有发现模型能够提出新假设、算法或架构，也没有发现它们能显著推进科学研究。作者指出，*现代 LLM 代理能够成功处理各种量化实验，体现了高级技能和领域适应能力*；但同时提醒，*尚不清楚科学新颖性这一概念能否被成功自动化，甚至能否被形式化为适用于智能体的定义*。

#### 23.2.8.2 电子商务

责任归属是智能体大语言模型应用于电子商务的一大障碍。安全和隐私顾虑可能使用户不愿向容易泄露数据的系统提供个人信息和偏好。这会造成推荐系统的两难处境：用户不愿详细说明真实偏好，推荐质量就可能下降；信任随之降低，用户也会更不愿分享信息。只有能够安全地收集高质量偏好信息，并提供有用的推荐，智能体大语言模型才可能在电子商务中获得公众采用。

#### 23.2.8.3 金融交易

金融交易中的责任问题至关重要。研究报告称，LLM 总结大量财务报告的能力可能胜过人工分析师，但金融交易风险很高，错误建议会直接造成损失。由于市场难以预测，发现模型缺陷可能需要时间：单次亏损可能源于模型错误，也可能只是交易运气不佳。模型在投入使用前应经过充分测试。除非自动化交易系统证明自身极为可靠，否则它们不太可能取代人工决策。

LLM 在金融领域最擅长分析文本报告。虽然一些金融时间序列研究报告了积极结果，但可靠、可验证的基准仍然难以建立。

Li 等 [2026] 则对智能体大语言模型能否可靠预测金融市场结果提出了质疑。

#### 23.2.8.4 医学

在医学领域，结果的准确性、尤其是可解释性，对建立信任至关重要。模型预测直接关系到责任归属和行动伦理，因此医疗智能体大语言模型系统必须让人类参与决策。
  
 与金融领域类似，智能体大语言模型在医学中最有前景的用途是分析和总结文本，例如会议记录或文献综述。治疗方案决策和手术等其他应用的结果仍有限。
 
医学或许是智能体大语言模型潜在价值最高、同时也最需要审慎应用的领域之一。面对生死攸关的问题，我们必须格外谨慎，同时也应看到其潜在收益。

## 23.3 结语

智能体大语言模型技术发展迅速。本书从三个相互关联的支柱追踪了这一发展：*推理*、*行动*和*交互*。推理型 LLM 通过思维链、自我反思和检索增强提供认知基础，使模型能够进行多步问题求解、文献综合和复杂决策支持。行动型智能体借助工具、API 和世界模型，将这些能力扩展到现实世界，协助用户处理从机器人到金融、医学等领域的任务。交互型智能体则进一步在多智能体模拟中彼此互动，呈现合作、信任和规范形成等并未由提示明确设定的涌现社会行为。

这三大支柱彼此相连。如图1.1所示，它们构成一个循环：推理推动更好的行动与交互，而智能体行动和交互产生的数据又可用于预训练和微调更强的推理模型。这一良性循环或可帮助突破 LLM 规模扩展的瓶颈。智能体助手、机器人系统和多智能体模拟产生的交互数据，可能持续补充多样且高质量的训练信号。

然而，这三大支柱仍面临重大挑战。幻觉会削弱人们对推理链的信任，并威胁自我改进系统的稳定性；高风险领域中行动型智能体的安全、责任归属和伦理问责问题仍未解决；大规模多智能体系统中的涌现行为也难以验证和控制。要克服这些挑战，还需研究机制可解释性、开放世界模型、可扩展的模拟基础设施和稳健的安全基准。

我们正处于一个早期但影响深远的阶段。概念验证令人印象深刻，现实世界的部署已开始；而记忆、元认知、意识和集体智能的理论基础仍有许多未解问题。这些问题将人工智能与哲学、认知科学和法律联系起来。本书旨在为你提供技术基础和概念工具，帮助你参与相关研究。该领域需要既了解智能体大语言模型当前能力与局限、又能帮助塑造其未来发展的研究者。
