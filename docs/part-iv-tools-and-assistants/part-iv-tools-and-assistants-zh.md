## 第四部分工具与助手

{1}------------------------------------------------

![](assets/_page_1_Picture_0.jpeg) 
 
{2}------------------------------------------------

前三部分介绍了构建高级 LLM 智能体所需的人工智能技术，使其能够与现实世界交互并采取行动，从而为用户完成有用的任务。本部分将讨论 LLM 如何通过学习到的 API（应用程序编程接口）使用工具执行特定任务，例如检索信息或控制机器人。

工具有助于解决预训练 LLM 的一项主要局限：模型所含信息的新旧程度取决于训练数据。检索增强技术可以让 LLM 提供最新信息。
  
本部分最后一章将介绍医学、金融和科学领域中的重要应用。随后，实践案例将综合运用这些技术，实现一个用于医学诊断的 LLM 智能体。
