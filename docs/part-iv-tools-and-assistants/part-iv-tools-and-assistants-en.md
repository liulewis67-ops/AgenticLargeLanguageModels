## Part IV Tools and Assistants

{1}------------------------------------------------

![](assets/_page_1_Picture_0.jpeg)

{2}------------------------------------------------

The first three parts introduced techniques for building advanced LLM agents that can interact with and act in the real world. These capabilities let agents perform useful tasks for their users. This part examines how LLMs use tools for specialized tasks, such as retrieving information or controlling robots, through learned APIs (application programming interfaces).

Tools can address a major limitation of pretrained LLMs: their information is only as current as the data on which they were trained. Retrieval-augmentation techniques allow LLMs to provide up-to-date information.

The final content chapter reviews agents in medicine, finance, and science. A practical case study then brings these technologies together as we implement an LLM agent for medical diagnosis.
