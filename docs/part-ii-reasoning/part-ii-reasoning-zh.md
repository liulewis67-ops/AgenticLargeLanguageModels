## 第二部分推理

{1}------------------------------------------------

![](assets/_page_1_Picture_0.jpeg) 
 
{2}------------------------------------------------

这一部分聚焦智能体的推理能力，以及它们如何借此学习。前一部分介绍了基础的下一个词元预测 LLM 如何训练。在智能体系统中，通常会使用能力更强的推理模型和多模态模型；本书仍将它们统称为 *LLM*。本部分将讨论这些模型为何必要，以及它们如何训练和使用。

本部分第一章介绍推理模型。早期的 LLM 甚至难以解决简单的推理问题，而思维链提示为这一领域带来了重要突破。我们将讨论数学应用题、思维链提示和上下文学习，也会介绍通过自我反思改进自身行为的模型。自我反思循环还推动了 LLM 智能体执行框架的发展。

下一章将从语言拓展到视觉和行动领域，介绍 Transformer 架构如何应用于这些领域，并讨论不同类型的世界模型，以及它们如何帮助智能体在与世界交互时采取更明智的行动。
  
本部分最后一章将介绍元学习。它是智能体大语言模型中多种学习方式背后的范式之一；我们将讨论元学习的含义，以及它为何具有挑战性。
