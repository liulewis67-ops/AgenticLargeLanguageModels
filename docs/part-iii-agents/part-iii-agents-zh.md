## 第三部分 智能体

{1}------------------------------------------------

![](assets/_page_1_Picture_0.jpeg) 
 
{2}------------------------------------------------

我们已经介绍了 LLM 和智能体的基础：语言与分词的工作方式、LLM 的训练与微调、推理模型如何进行推理和自我反思，以及学习如何拓展到语言、视觉和行动领域。我们还讨论了元学习的复杂性。

接下来，我们将转向智能体大语言模型研究的核心议题：LLM 智能体的不同交互方式。本部分包括一章理论内容和一个实践案例。我们先回顾此前介绍过的五种智能体交互方式，并讨论记忆的重要性；随后通过实践案例综合运用这些方法，构建一个能够游玩 TextWorld、NetHack 等典型 AI 游戏的自我反思型 LLM 智能体。
