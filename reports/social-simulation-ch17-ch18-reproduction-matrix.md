**先执行操纵检查。** 在固定 Go 源码里：原始带符号效价 → 绝对值 → 候选集合内 min–max → 原始负值按 `NegativityBias` 乘倍数 → 全项按 `ValenceWeight` 参与总和。**当 `valence_w=0`，即使 `negativity_bias=1.5`，该项总贡献仍为 0**。负效价的 1.5 倍在归一化后发生，因此最终效价项不一定在 [0,1]。需先用正负同幅度、零效价、全部相等、缺失和重分进行确定性样例测试。

## 2. 最小 2×2 双机制消融 / Factorial arms

上游课程的 Exercise 3 同时打开**效价加权检索**与**非对称感官编码**；所以应该按这两个实际实现机制独立控制，不能仅仅设置“原始/NEVER”两个模糊标签。

| 条件 ID | 效价检索 R | 非对称编码 E | 配置意图 | 问题 |
| --- | ---: | ---: | --- | --- |
| R0E0 | 关 | 关 | `valence_w=0`；`asymetric_encoding=false` | 完整基线 |
| R1E0 | 开 | 关 | `valence_w>0`、`negativity_bias=1.5`；`asymetric_encoding=false` | 单独检索加权的效果 |
| R0E1 | 关 | 开 | `valence_w=0`；`asymetric_encoding=true` | 单独感官编码的效果 |
| R1E1 | 开 | 开 | `valence_w>0`、`negativity_bias=1.5`；`asymetric_encoding=true` | 联合效果及交互作用 |

`asymetric_encoding` 是审计版上游项目的**实际字段拼写**，不要凭英语语法改成另一个键。所有检索开启条件须固定 `valence_w` 选定正数及其在不同 run 中的数值；其余三项权重以及原始记忆候选、截断的检索条数应保持不变。检索关闭条件要将 `valence_w=0`，避免只修改负面倍率却没有有效处理。

### 先解决人物混杂

原作者意图把 Dolores/Maeve 作为相同人格下的处理/对照，但在先前固定的公开 `scratch.json` 中，二人的 `learned`、日程和生活方式并非完全相同。严谨的单因素比较应把**同一人格/日程模板**复制给所有条件，或使用交叉交换角色与处理的设计。Bernard 的个人设定和随机行为也需固定/分组。人格提示变化应作为**另一套实验**，不能不加区分地混入上述 2×2 检索×编码效应。

## 3. 独立重复、配对与指标 / Unit of analysis

- **独立实验单位：完整模拟运行**，每个 run 独立初始化世界、网络和随机过程。对四组条件使用匹配 seeds/同一初始条件进行配对，同时跨不同初始种子重复。千万不要把单次模拟产生的数千条消息或两个角色当作数千个独立实验对象。
- 固定且记录完整轮数（例如课程建议至少 30 分钟**游戏内时间**）、采样参数、模型调用次数/总 token/费用和时间预算、事件采样粒度。停止规则在运行前预注册。
- 分别检查操纵是否成立：**改变了哪些候选记忆的排序及入选集合**，负面记忆实际占比是否变化；感官编码是否确实扩展了负面事件描述；并记录记忆检索对下游生成提示的影响。
- 主要终点事先指定：例如平均情绪效价、负面交互比率、冲突事件率、社交联系变化、偏离原计划的次数；必须写明单位、分母与裁判定义。给出**每个完整 run 的结果**、平均值/离散程度和跨 run 置信区间。
- 估计 `R` 主效应、`E` 主效应和交互项 `R×E`；若配置或模型导致行为高度相关，采用按 run 分组的 bootstrap / 混合效应模型，并报告区间和未产生效应的失败试验。对裁判/效价 LLM 实施盲评、人工抽查和评分器一致性验证。

## 5. 第 17 章的群体涌现反证协议

设立无互动、消息随机置换、固定脚本通信、自由互动的四类控制，记录规范形成的初始条件、网络生成方式、分组人口及更新顺序。对命名游戏或舆情传播，预注册收敛定义、规范转向阈值、失败率、完整模拟的独立种子及多重比较策略。

尤其注意：
- 一个 run 中的一百万名**模拟用户**不等于一百万个**独立的 LLM 推理进程**，也不等于一百万次独立实验。
- OASIS 对百万用户规模报告的高算力消耗是特定配置的资源报告，不是无需成本的通用部署能力；需固定原论文版本、模型与 GPU / 每时间步预算。
- 命名博弈、文化规范、平台舆论的仿真结果，只能在显式测量并控制人格、网络、调度和外部数据差异后讨论与现实的可比性。

**核验状态：本模板未执行任何模拟。** 现存 `scripts/audit-formula-regressions.mjs` 仅对部分数学分支做了独立的算术冒烟测试，不代表实际 Go 程序或 LLM 推理被复现。
