# 多智能体与社会模拟的实验审计协议

> 适用于本仓库第 14–18 章的研究设计和审校复核。**这是编者设计的可执行审计模板，不是原书作者的实验协议，也不代表我们已实际运行相关实验。**

## 1. 定义清楚研究问题

提交实验前填写：

| 字段 | 需明确的信息 |
| --- | --- |
| 研究问题 | 例如：角色分工是否在**相同计算预算**下提高任务成功率？ |
| 主要假设 / 估计目标 | 定义处理组与对照组的平均结果差异；注明目标人群或模拟环境 |
| 操纵因素 | 智能体数量、角色、通信、记忆权重、网络拓扑或提示 |
| 主要结果指标 | 预先定义成功率、端到端错误、冲突率、规范形成率或成本 |
| 分析单位 | 一份独立病例、一个独立游戏对局，或一次完整模拟，而**不是每次模型调用** |
| 版本与种子 | 仓库提交、模型快照、依赖锁、提示模板、种子、温度、环境初始化 |
| 外部效度目标 | 仅模拟平台内、其他模型／游戏，还是需要对现实人群进行推断 |

## 2. 多智能体的因果对照设计

尽可能比较以下条件，按研究问题调整：

1. **单智能体基线**：没有角色分工；固定总推理预算。
2. **单智能体反思**：允许额外思考但与多智能体使用**同等总调用数、token、工具次数或延迟预算**。
3. **独立采样并聚合**：多个彼此不通信的模型输出通过相同的聚合器决策，以排除纯粹“多次尝试”的效应。
4. **多智能体但无明确角色**：允许交流，取消角色分工。
5. **多智能体明确角色**：保持其他要素相同，仅增加拟研究的角色与协议。

此外分别消融角色提示、通信轮数、共享记忆和工具权限。只要不同组同时改变多个要素，**就无法单独识别角色分工的因果效应**。报告每组的资源预算，而不只报告最终得分。

## 3. 避免伪重复与评测器偏差

- **独立性：** 多个智能体在同一对局／模拟中的发言、消息与行动高度相关。应以独立生成的完整对局／模拟或经过分组的数据单位估计不确定性。
- **配对：** 尽量在同一案例、地图、场景或共同随机种子下比较对照组和处理组；应说明配对是否真正可行，以及随机过程是否会在不同策略下分叉。
- **不确定性：** 给出每组样本量、效果量、置信区间或预先声明的重采样区间；对重大差异做稳健性和敏感性分析。
- **多重检验：** 若比较大量任务、模型、游戏和指标，预先标明主要终点并说明多重比较处理方法；把探索性发现与确认性检验分开报告。
- **盲评与标准答案：** 多数投票、LLM 裁判偏好与独立事实正确性是不同指标。尽可能采用独立参考答案和盲法人工标注；记录裁判模型和评分脚本版本。
- **失败日志：** 记录超时、拒答、上下文截断、异常循环、路由失败、上下游错误和中止原因；不能只统计成功完成的试验。

## 4. 行为机制、因果与外部效度

对“涌现合作／道德能力／心智理论／负面偏向影响”等研究结论：

- **行为层：** 结果确实显示何种可观察行为？是否可以由模板、语言先验、重复记忆或奖励设计解释？
- **干预层：** 是否通过消融和随机化，排除了角色脚本、初始偏见、模型权重、网络拓扑及额外计算预算的替代解释？
- **机制层：** 是否有真正的过程证据与干预检验，还是只根据输出推断内部心理机制？
- **外部效度：** 模拟中的人群构成、社会网络、交互频率、环境约束和时间尺度，是否有可追溯的人类行为数据作独立校准？
- **结论层：** 若只有模拟实验，应限定为“在指定模拟环境中观察到”，不应升级为真实人群规律或政策有效性的证明。

## 5. 第 14 / 18 章特别复核

**第 14 章诊断案例：** 验证由三个来源数据集拼接的模拟病例是否造成标签或来源泄漏；在独立留出案例上分别估计规划器路由与执行器分类误差，并记录拒答与人工接管。不得视为临床诊断研究。

**第 18 章负面记忆实验：** 固定 2×2 因子设计（人格提示 × 记忆机制），先独立测试公式 (18.1) 中效价项 `V` 的计算约定，特别是负面记忆 **1.5 倍**在归一化和评分中的位置；再做独立的多种子完整模拟。人格与记忆的主效应及交互效应要分开报告。

## 6. 推荐输出记录结构

实验结果至少包含：

```text
experiment_id, source_commit, model_snapshot, prompt_revision
condition, seed, environment_id, independent_run_id, input_case_id
agents_count, tokens_total, calls_total, tool_calls, elapsed_ms
outcome_primary, outcome_secondary, failure_reason
judge_version, scoring_protocol_version, notes
```

**验证等级：**仅完成方案检查 ≠ 代码运行通过 ≠ 重复实验结果稳定 ≠ 与原论文成功复现 ≠ 已证明真实世界有效。每项结果必须单独标注证据等级；没有数据时不应填入统计显著性、置信区间或样本量。
