## 二、第 11 章：LangChain 兼容性与 MCP 边界

**T-11-01（API 版本）**：清单 11.1 中出现旧式 `agent.run(user_prompt)`。LangChain v1 Python 推荐 `langchain.agents.create_agent` 和基于消息的 `invoke`。因此同一代码不能未经核对就宣称“用最新版本一键运行”。在清单后新增中英标注的*非原文编者 API 兼容性提示*，保留原例以便和书稿核对；不虚构已执行成功的结果。

**T-11-02（协议概念）**：原书第 11.4 节把 MCP 的工具接入机制与长期对话摘要、任务记忆混在同一讨论中。MCP 提供标准化工具/资源/提示的访问接口，但**不规定宿主应用的摘要、持久化记忆或高风险操作授权策略**。中文版已有此区别，英文补充明确说明，尤其标明 LangChain 的摘要示例不是 MCP 协议实现。

**T-11-03（工具安全）**：保留之前已有的提示注入与最小权限编者说明，强调外部文档/网页属于低信任输入；不能用 LLM 自行判断取代宿主侧参数校验、审计和人类审批。

## 三、第 12 章：公式 (12.5) 的确定性勘误

书稿给出的 BM25 形式包含 `IDF(t,d)`，而同一章公式 (12.2) 定义的是 `IDF(t,D)`。后者符合文档频率是**整个语料集合统计量**的含义；`f_{t,d}` 和 `|d|` 才依赖具体文档。

因此 `IDF(t,d)` 属于**可由原书相邻公式与数学定义共同判断的变量错误**。为最大化原文可追溯性，**保留原书 (12.5) 的原样排印**，并在其后添加注明“非原文”的双语公式勘误，而不默默改写源方程。BM25 实际实现常使用平滑概率式 IDF，不能假定一定等同于原书 (12.2) 的 `log(N/df)`；复现时必须记录分词和 IDF 约定。

**T-12-02（检索指标边界）**：MRR 遇到未找出任何相关结果时，倒数排名记为 0；当查询没有相关 ground truth 时 Recall@k 分母为 0；当理想 DCG 为 0 时 nDCG@k 也不能直接相除。统一说明评测实现必须定义“排除/按固定策略计分”，并测试空结果、重分、重复 ID 与不完整标注。原书的简式公式没有明确这些零分母/缺失值规则。

**算术烟雾测试**：在 `scripts/audit-source-fidelity.mjs` 中加入有固定值的 BM25 基本性质检查：语料 IDF 为正；固定文档长度时增加词频使单词项得分升高；固定词频时更短文档的 BM25 词项分数更高；MRR 对排名 `[1, 2, 无相关结果]` 得 `(1 + 1/2 + 0)/3 = 0.5`。这些是自包含数值反例，**不是学术论文复现或全功能检索系统测试**。

## 四、第 13 章：来自临床随机试验的结果不能偏读

原书第 13.5 节说部分模型在诊断任务上超越受训医生，并引用 Goh 等人。经对照 [2024 年 10 月 28 日正式发表的 JAMA Network Open 研究](https://doi.org/10.1001/jamanetworkopen.2024.40969)：

- 该研究纳入 **50 名医生**，使用 **6 个临床病例情景**，对比医生使用常规资源和使用 LLM 辅助的诊断推理表现，另外评估 LLM 单独回答的分数。
- **LLM 单独回答的指标得分较高**，但**医生有 LLM 可用的组别，相对只用常规资源的组别并没有统计显著改善**。
- 这并非对真实前瞻性临床部署、安全性或患者结局的验证。不能把“LLM 单独得分高”替换成“医生引入 LLM 获得改善”或“AI 可安全替代医生”。

中英正文相应段落之后增添显式注明**非原文**的研究结果解释，并链接论文 DOI。保留其他医疗、金融回测与科研智能体风险边界的既有编者提示。
